研究主故事

不是再造一个更大的试验平台，而是在数字线程和正式决策之间增加一个明确、可审计、可失效的证据治理边界。
Problem

“数据存在” ≠ “可以用于当前决策”

模型、试验、报告、指标即使都可追溯，也可能属于另一个 Case、承担错误角色、超出验证域，或已经因来源变化而失效。

Mechanism

ORED：四层治理编译器

把 Case-scoped objects 编译为 typed relations，再变成 admissible evidence，最后才进入 governed decisions。

Evidence

四个边界 gate，而非四项功能

v2.3.1–v2.3.4 分别验证跨 Case 迁移、关系隔离、受控复用和来源变化后的自动撤销/传播。

冻结规则与研究边界

这一块决定研究是否可信：哪些事情现在允许做，哪些事情即使能做也不能做。
允许：外部 vocabulary adapter、artifact parser、evidence import manifest、source-specific field normalization。
禁止：看到 PAS 2161 outcome 后给 resolver / evidence admission / decision core 增加 PAS2161-specific branch。
允许：如果官方在 outcome 打开前发布 2026 criteria 变化，更新外部 policy version 并留痕。
禁止：按最终 demonstrated / not-demonstrated 结果重新选择 holdout、改 negative controls、改成功标准。
允许：Tier B/C 如实报告 mapping 或可行性子集。
禁止：没有完整 technology-level metrics 时，用 2025 汇总结果或 certificate 冒充 independent decision reconstruction。

当前可以说什么 / 不能说什么

Supported now
  • ORED 四层在两个内部 demo Case 上可执行并 fail closed。
  • 跨 Case 复用与 stale propagation 已通过内部 deterministic gates。
  • PAS 2161 公开 artifact classes 可映射到现有四层，不需第五层。
Not supported yet
  • 不能声称 ORED 已通过独立外部工程验证。
  • 不能声称 decision reconstruction 已成功。
  • 不能声称适用于所有组织、监管制度或复杂等效性判断。
