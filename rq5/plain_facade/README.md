# BL-01 — three-arm ablation

Arms: (1) direct coupling, (2) competent plain facade, and (3) SAL/TMSU.

The plain facade intentionally provides software isolation but omits TMSU semantic profiles, intended-use state, evidence dependencies, and lifecycle rules. This design tests the reviewer's central challenge directly: generic adapters can localize code; the claimed SAL/TMSU increment is T&E governance attached to the boundary.

The experiment reports software-localization and governance outcomes separately. LOC is descriptive only and is not interpreted as engineering cost.
